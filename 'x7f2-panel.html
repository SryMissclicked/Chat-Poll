Design
Zuschauer stimmen ab, indem sie die passende Zahl (z. B. 1) im Twitch-Chat schreiben. Kein Bot, kein Login nötig — es wird nur der öffentliche Chat live mitgelesen.
Trag diesen Link einmalig als Browser-Quelle in OBS ein. Er bleibt danach immer gleich — auch wenn du hier neue Fragen erstellst.
Diesen Befehl in deinen eigenen Twitch-Chat posten, um die Umfrage live zu starten. Zum Beenden: !endpoll posten.
Bereit
Das kariert schraffierte Feld zeigt den transparenten Hintergrund — so sieht es später in OBS als Browser-Quelle aus. Exportiere die Datei und hänge ?view=overlay an die URL, mit der du sie hostest (z. B. GitHub Pages, Netlify).
